---
title: Account Recovery
description: Steps to recover your account if you have lost access
---

If a user has lost their passkeys, reset them. This removes all passkeys of the user, signs them out on all devices and creates a single-use enrollment code. The user clicks **Set up a passkey** on the login page and enters the code within 24 hours to create a new passkey.

There are two ways to reset the passkeys of a user:

1. **UI**: An admin opens **Admin → User Management**, clicks on the three dots next to the user, selects **Edit** and then **Reset passkeys**.
2. **Terminal**: If no admin can log in anymore, run `hub reset-passkeys` with the email address or ID of the user:

```bash
docker compose exec hub /app/hub reset-passkeys --email <email>
```

<AccountRecoveryTerminal />

<Callout type="warn">
	Only users with a local account have passkeys. Users that only log in via SSO have to recover
	their account at the identity provider. If `DISABLE_LOCAL_AUTH=true` is set, enrollment codes
	can't be used until the variable is removed.
</Callout>

If no user exists yet and you lost the setup code for the first admin account, restart the Hub. A new setup code is printed to the logs on every start (`docker compose logs hub`).
