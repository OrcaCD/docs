---
title: Environment Variables
description: Complete reference for all OrcaCD configuration options
---

With the default `docker-compose.yml`, the Hub reads its variables from `.env` and the Agent from `agent.env`.

Each variable is tagged with a **Type**:

- <Badge variant="red">Required</Badge> - OrcaCD will not function correctly without this being set.
- <Badge variant="amber">Recommended</Badge> - optional, but recommended to change
- <Badge variant="purple">Security</Badge> - optional, but recommended to harden your deployment.
- <Badge variant="gray">Optional</Badge> - safe to leave at the default value.

## General

These environment variables can be used in both the agent and the hub.

| Variable    | Default Value | Type                                   | Description                                                                                          |
| ----------- | ------------- | -------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `LOG_LEVEL` | `info`        | <Badge variant="gray">Optional</Badge> | Log level: `trace`, `debug`, `info`, `warn`, `error` or `fatal`. The setup code is logged as `warn`. |
| `LOG_JSON`  | `false`       | <Badge variant="gray">Optional</Badge> | Log in JSON format.                                                                                  |

## Hub

| Variable               | Default Value | Type                                       | Description                                                                                                                                                                                 |
| ---------------------- | ------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `APP_URL`              | `-`           | <Badge variant="red">Required</Badge>      | Public URL of the Hub, e.g. `https://orcacd.example.com`, without a path. Must match the URL in the browser. Login requires HTTPS, except on `localhost`.                                   |
| `APP_SECRET`           | `-`           | <Badge variant="red">Required</Badge>      | Secret for authentication and database encryption, at least 32 characters. Generate one with `openssl rand -base64 42`. See [`hub key rotate`](/docs/advanced/cli#key-rotate) to change it. |
| `TRUSTED_PROXIES`      | `-`           | <Badge variant="amber">Recommended</Badge> | Comma separated IPs or CIDR ranges of your reverse proxies.                                                                                                                                 |
| `DISABLE_LOCAL_AUTH`   | `false`       | <Badge variant="purple">Security</Badge>   | Disable password login, e.g. when using [OIDC](/docs/guides/oidc).                                                                                                                          |
| `ALLOWED_IPS`          | `-`           | <Badge variant="purple">Security</Badge>   | Comma separated IPs or CIDR ranges that can access the Hub. Webhooks, GitHub Actions, the health check and Agent connections are always allowed.                                            |
| `HOST`                 | `-`           | <Badge variant="gray">Optional</Badge>     | Address the Hub listens on. Defaults to all interfaces.                                                                                                                                     |
| `PORT`                 | `8080`        | <Badge variant="gray">Optional</Badge>     | Port the Hub listens on.                                                                                                                                                                    |
| `DISABLE_UI`           | `false`       | <Badge variant="gray">Optional</Badge>     | Don't serve the web UI, e.g. for API-only use.                                                                                                                                              |
| `ALLOWED_INTERNAL_IPS` | `-`           | <Badge variant="gray">Optional</Badge>     | Comma separated private IPs or CIDR ranges the Hub may connect to, e.g. a self-hosted Git server or OIDC provider.                                                                          |
| `DEMO`                 | `false`       | <Badge variant="gray">Optional</Badge>     | Demo mode: seeds demo data and disables everything except the login.                                                                                                                        |

## Agent

<Callout type="warn">
	Deployed Compose files can read the Agent's environment. Never give the Agent the `.env` file of
	the Hub.
</Callout>

| Variable                              | Default Value  | Type                                     | Description                                                                                                                                           |
| ------------------------------------- | -------------- | ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `HUB_URL`                             | `-`            | <Badge variant="red">Required</Badge>    | URL of the Hub, usually the same as `APP_URL`.                                                                                                        |
| `AUTH_TOKEN`                          | `-`            | <Badge variant="red">Required</Badge>    | Token of the Agent, created when you add the Agent in the Hub.                                                                                        |
| `RESTRICT_VOLUMES_TO_DEPLOYMENTS_DIR` | `false`        | <Badge variant="purple">Security</Badge> | Only allow host paths inside the deployment directory of the application. See [deployment policy](/docs/advanced/security#compose-deployment-policy). |
| `ALLOWED_PRIVILEGED_APPS`             | `-`            | <Badge variant="gray">Optional</Badge>   | Comma separated application IDs that skip the [deployment policy](/docs/advanced/security#compose-deployment-policy) entirely.                        |
| `CA_CERT_FILE`                        | `-`            | <Badge variant="gray">Optional</Badge>   | Path to a PEM CA certificate inside the Agent container, for Hubs with a self-signed or private CA certificate.                                       |
| `HEALTHCHECK_PORT`                    | `8090`         | <Badge variant="gray">Optional</Badge>   | Port of the internal health check endpoint on `127.0.0.1`.                                                                                            |
| `DEPLOYMENTS_DIR`                     | `/deployments` | <Badge variant="gray">Optional</Badge>   | Directory inside the Agent container where deployments are stored. Must be mounted from the host.                                                     |
