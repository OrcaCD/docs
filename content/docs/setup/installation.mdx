## Prerequisites

OrcaCD consists of two components: the **Hub**, the central control plane that serves the web UI and manages your deployments, and the **Agent**, which runs on every machine where applications should be deployed and executes the deployments there. One Hub can manage many Agents on different machines, but both can also run together on a single machine, which is what this quickstart sets up. See the [architecture overview](../advanced/architecture/overview) for more details.

Before you start, make sure you have:

- A machine to run the Hub and Agent on - typically a Linux server like a VPS, but any machine with Docker works
- [Docker Engine](https://docs.docker.com/engine/install/) with the [Docker Compose plugin](https://docs.docker.com/compose/install/) installed.
- For a publicly reachable setup: a domain with a DNS record pointing to your server, and a reverse proxy which also handles TLS. By default the Hub only listens on `127.0.0.1:8080`, and you put your own reverse proxy (Nginx, Caddy, Traefik, ...) in front of it. See the [reverse proxy guide](../guides/reverse-proxy).

<Callout>
	Just testing OrcaCD locally? You can skip the domain and reverse proxy setup, set
	`APP_URL=http://localhost:8080` in the `.env` file and `HUB_URL=http://hub:8080` in the
	`agent.env` file, and access the Hub at `http://localhost:8080`.
</Callout>

## Start Hub and Agent [step]

Download the [`docker-compose.yml`](https://raw.githubusercontent.com/OrcaCD/orca-cd/main/docker-compose.yml), the [`.env`](https://raw.githubusercontent.com/OrcaCD/orca-cd/main/.env.example) file for the Hub and the [`agent.env`](https://raw.githubusercontent.com/OrcaCD/orca-cd/main/agent.env.example) file for the Agent:

```bash tab="curl"
curl -o docker-compose.yml https://raw.githubusercontent.com/OrcaCD/orca-cd/main/docker-compose.yml
curl -o .env https://raw.githubusercontent.com/OrcaCD/orca-cd/main/.env.example
curl -o agent.env https://raw.githubusercontent.com/OrcaCD/orca-cd/main/agent.env.example
```

```bash tab="wget"
wget -O docker-compose.yml https://raw.githubusercontent.com/OrcaCD/orca-cd/main/docker-compose.yml
wget -O .env https://raw.githubusercontent.com/OrcaCD/orca-cd/main/.env.example
wget -O agent.env https://raw.githubusercontent.com/OrcaCD/orca-cd/main/agent.env.example
```

Edit both files according to the instructions in them. The most important values in the `.env` file of the Hub are:

- `APP_URL` - the URL under which the Hub will be reachable. OrcaCD does not provision this URL for you: it is your domain pointing at your reverse proxy (e.g. `https://orcacd.example.com`).
- `APP_SECRET` - used for authentication and database encryption. Generate one with `openssl rand -base64 42`.

In the `agent.env` file of the Agent:

- `HUB_URL` - the URL the Agent uses to reach the Hub, usually the same as `APP_URL`.
- `AUTH_TOKEN` - leave empty for now; you will create it in the Hub UI in a later step.

<Callout type="warn">
	Do not put `APP_SECRET` into the `agent.env` file or give the Agent the `.env` file of the Hub.
	Compose files deployed by the Agent can read the Agent's environment.
</Callout>

We recommend customizing other environment variables as needed.
See the [environment variables page](../configuration/env-variables) for more details.

<Callout>
	Remove the Agent part from the compose file if you don't want to deploy it to the same machine as
	the Hub.
</Callout>

Start the Hub and the Agent:

```bash
docker compose up -d
```

## Configure your Reverse Proxy [step]

By default the hub only listens on port `8080` on localhost. Configure your reverse proxy to forward traffic from your domain to the Hub. See the [reverse proxy guide](../guides/reverse-proxy) for instructions for Nginx, Caddy and Traefik.

## Create an Admin Account [step]

As long as no user exists, the Hub prints a one-time setup code to its logs on every start. You need this code to create the first admin account:

```bash
docker compose logs hub | grep setup-code
```

The log entry also contains a link like `https://orcacd.example.com/register#setup-code=XXXX-XXXX-XXXX-XXXX`. Open it to get the code filled in automatically, or open `https://orcacd.example.com/register` and enter the code manually. The password must be at least 12 characters long and include an uppercase letter, a lowercase letter, a number and a special character.

![Setup Admin Account](/assets/docs/account-setup.png?url)

## Connect your first Agent [step]

Navigate to the Agents page, click "Add Agent" and enter a name. The setup dialog shows the generated token and a `compose.yml` for the Agent. As the Agent from this quickstart is already part of your `docker-compose.yml`, select **Copy agent auth token** in the menu next to **Copy** and add the token as `AUTH_TOKEN` to the `agent.env` file. Then recreate the Agent container so it picks up the new value (a plain `docker compose restart` does not reload the env file):

```bash
docker compose up -d agent
```

![Setup Agent](/assets/docs/create-agent.png?url)

The dialog waits for the first connection and switches to **Connected** as soon as the Agent is online. The token is only shown once.

## Start Deploying [step]

Add your first repository and create your first deployment. Connect a [OIDC provider](../guides/oidc) to allow your team to log in or invite them on the admin page.
