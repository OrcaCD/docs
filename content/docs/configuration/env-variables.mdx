title: Environment Variables
description: Complete reference for all OrcaCD configuration options

Below are all the environment variables supported by OrcaCD. These should be configured in your `.env` file.
Be cautious when modifying environment variables that are not recommended to change.

Each variable is tagged with a **Type**:

- <Badge variant="red">Required</Badge> - OrcaCD will not function correctly without this being set.
- <Badge variant="amber">Recommended</Badge> - optional, but recommended to change
- <Badge variant="purple">Security</Badge> - optional, but recommended to harden your deployment.
- <Badge variant="gray">Optional</Badge> - safe to leave at the default value.

## General

These environment variables can be used in both the agent and the hub.

| Variable    | Default Value | Type                                   | Description                                                                                                                                                                           |
| ----------- | ------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `LOG_LEVEL` | `info`        | <Badge variant="gray">Optional</Badge> | Log level. Options: trace, debug, info, warn, error, fatal. The setup code for the first admin account is logged with the `warn` level, so it is not visible with `error` or `fatal`. |
| `LOG_JSON`  | `false`       | <Badge variant="gray">Optional</Badge> | Enable JSON formatted logs.                                                                                                                                                           |

## Hub

| Variable               | Default Value | Type                                       | Description                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------- | ------------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `APP_URL`              | `-`           | <Badge variant="red">Required</Badge>      | The public URL of the OrcaCD instance, e.g. `https://orcacd.example.com`. Only scheme, host and an optional port are allowed: a path, query string or fragment is rejected. It must exactly match the URL in the browser, because the `Origin` header of every state-changing request is compared with it. The login cookie is always marked as `Secure`, so logging in only works via HTTPS or on `localhost`. |
| `APP_SECRET`           | `-`           | <Badge variant="red">Required</Badge>      | Secret used for authentication and database encryption. Must be at least 32 characters long, otherwise the Hub refuses to start. Generate one with `openssl rand -base64 42`. To change it later, use [`hub key rotate`](/docs/advanced/cli#key-rotate) and re-issue all agent tokens afterwards.                                                                                                               |
| `TRUSTED_PROXIES`      | `-`           | <Badge variant="amber">Recommended</Badge> | Recommended if using a reverse proxy. Comma separated list of network origins.                                                                                                                                                                                                                                                                                                                                  |
| `DISABLE_LOCAL_AUTH`   | `false`       | <Badge variant="purple">Security</Badge>   | Disable password authentication. Useful when using [SSO with OIDC](/docs/guides/oidc).                                                                                                                                                                                                                                                                                                                          |
| `ALLOWED_IPS`          | `-`           | <Badge variant="purple">Security</Badge>   | Harden the hub by only allowing requests from certain IPs. Comma separated list of CIDR ranges or single IPs. Does not apply to webhooks (`/api/v1/webhooks/*`), GitHub Actions (`/api/v1/github-actions`), the health check (`/api/v1/health`) and agent connections (`/api/v1/ws`).                                                                                                                           |
| `HOST`                 | `-`           | <Badge variant="gray">Optional</Badge>     | Address the Hub listens on. If empty, the Hub listens on all interfaces (IPv4 and IPv6).                                                                                                                                                                                                                                                                                                                        |
| `PORT`                 | `8080`        | <Badge variant="gray">Optional</Badge>     | Container port                                                                                                                                                                                                                                                                                                                                                                                                  |
| `DISABLE_UI`           | `false`       | <Badge variant="gray">Optional</Badge>     | Disable serving the frontend. Useful when using the hub only for API access.                                                                                                                                                                                                                                                                                                                                    |
| `ALLOWED_INTERNAL_IPS` | `-`           | <Badge variant="gray">Optional</Badge>     | Private IPs that should be ignored by the SSRF protection, e.g. for a self-hosted Git server or OIDC provider. Comma separated list of CIDR ranges or single IPs.                                                                                                                                                                                                                                               |
| `DEMO`                 | `false`       | <Badge variant="gray">Optional</Badge>     | This mode disables all functions except the login and additionally seeds some demo data in the database                                                                                                                                                                                                                                                                                                         |

## Agent

| Variable                              | Default Value  | Type                                     | Description                                                                                                                                                                                                                                                                                                                                                                             |
| ------------------------------------- | -------------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `HUB_URL`                             | `-`            | <Badge variant="red">Required</Badge>    | The URL of the Hub. Example: `https://example.com`. Accepts `http`, `https`, `ws` and `wss` (`http` is converted to `ws`, `https` to `wss`). Without a path, `/api/v1/ws` is used; any other path is used as-is.                                                                                                                                                                        |
| `AUTH_TOKEN`                          | `-`            | <Badge variant="red">Required</Badge>    | The authentication token of the agent. Register an agent in the hub frontend to retrieve it.                                                                                                                                                                                                                                                                                            |
| `RESTRICT_VOLUMES_TO_DEPLOYMENTS_DIR` | `false`        | <Badge variant="purple">Security</Badge> | Only allow bind mounts and `env_file` paths inside the deployments directory. This enhances security. See [deployment policy](/docs/advanced/security#compose-deployment-policy).                                                                                                                                                                                                       |
| `ALLOWED_PRIVILEGED_APPS`             | `-`            | <Badge variant="gray">Optional</Badge>   | Comma separated list of application IDs that skip **all** checks of the [deployment policy](/docs/advanced/security#compose-deployment-policy), including `RESTRICT_VOLUMES_TO_DEPLOYMENTS_DIR`. Only add applications you fully trust.                                                                                                                                                 |
| `CA_CERT_FILE`                        | `-`            | <Badge variant="gray">Optional</Badge>   | Path inside the agent container to a PEM encoded CA certificate (bundle) used to verify the TLS certificate of the Hub, e.g. for self-signed certificates or a private CA. The certificates are added to the system CAs and do not replace them. The file has to be mounted into the container. If the file can not be read or contains no valid certificate, the agent does not start. |
| `HEALTHCHECK_PORT`                    | `8090`         | <Badge variant="gray">Optional</Badge>   | Port of the internal health check endpoint used by the Docker healthcheck. Only listens on `127.0.0.1`.                                                                                                                                                                                                                                                                                 |
| `DEPLOYMENTS_DIR`                     | `/deployments` | <Badge variant="gray">Optional</Badge>   | Directory inside the agent container where the deployments are stored. Mount it from the host as a bind mount or a local named volume, so the agent can translate bind mounts of your Compose files to host paths.                                                                                                                                                                      |
